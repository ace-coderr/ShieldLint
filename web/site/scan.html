01 Reading a result

What the output means.

A finding is not a style opinion. It is a decoded value, a location and a consequence you can verify against the specification.

Rule id

SL006

The rule that fired. Every id maps to a page in the rule index with the rationale, a bad example and the fixed version.

Severity

error / warning

Error means privacy is lost or the payment will not work. Warning means a weaker configuration that a sender or an observer can exploit.

Location

file:line:column

Points at the literal, not the statement — so an editor annotation or a SARIF viewer lands on the exact string.

Findings respect suppression. Add # shieldlint: ignore[SL002] on the line, or # shieldlint: disable-file at the top of a file, and the finding disappears — useful for vendored test vectors.
