ShieldLint

Offline privacy linting for Zcash. Privacy has no compile error — this is the compiler diagnostic.

GitHub ↗ Rules ↗ API
Nothing leaves your browser session. The scanner is stateless: code is analysed in memory and discarded — no accounts, no storage, no telemetry. Run the same engine locally with git clone github.com/ace-coderr/ShieldLint && pip install -e ..

Supports Python, JS/TS, Rust, Go, Java, C/C++, Ruby, PHP, YAML, TOML…

Decodes ZIP 316 Unified Addresses (incl. F4Jumble), Sapling, transparent and Sprout. Shows every receiver, the revision, the network and whether a sender can downgrade to transparent.

Full ZIP 321 grammar and semantics: parameter indexes, base64url memos, the 512-byte limit, amount formatting, req- parameters, memo-on-transparent, Sprout.

14 rules, each tied to a specification and shipped with a rationale.
